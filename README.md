# Flood Disaster Relief Distribution System

*Visual Dashboard | DSA + OOP Project**  
*B.Tech (AIDS) | Amrita Vishwa Vidyapeetham, Delhi NCR**

A complete Flood Disaster Relief Distribution System that simulates real-time relief allocation using **Data Structures and Algorithms**. The system features an interactive visual dashboard built with **Python + Tkinter**.

---

# Project Overview

During floods, efficient distribution of food, water, and medicine is critical. This project models:

- Affected villages with different flood severity levels
- Relief centers with resource stocks
- Road network (with flooded/damaged roads)
- Request queue processing using **FIFO** and **Priority Queue**
- Optimal path finding using **Dijkstra** and **BFS**

---

#  Key Features

- Interactive **Visual Dashboard** (Tkinter)
- Real-time simulation of relief requests
- **FIFO** vs **Priority-based** request handling
- **Dijkstra’s Algorithm** for shortest path (with road condition penalties)
- **BFS** for nearest center finding
- Resource inventory tracking with live bars
- Sorting algorithm comparison (Bubble, Selection, Merge, Heap Sort)
- Color-coded map based on flood severity
